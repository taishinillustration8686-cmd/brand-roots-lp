# BRAND ROOTS ｜ 個別相談 LP

愛知の個人事業主・クリエイター向け「ブランド構築 個別相談（90分・無料）」のランディングページ。

## 構成

```
index.html        LP本体
privacy.html      プライバシーポリシー
css/style.css     スタイル
js/script.js      スクロール演出・フォーム送信
img/              画像素材
```

## 申込みフォームについて

送信には [FormSubmit](https://formsubmit.co/) を使用しています。

**公開後、初回に1度だけアクティベーションが必要です。**

1. フォームから1件テスト送信する
2. 登録メールアドレスに FormSubmit から確認メールが届く
3. メール内の「Activate Form」を押す

この操作をしないと申込みが届きません。

## ローカルで確認する

```bash
python3 -m http.server 8000
# http://localhost:8000
```
